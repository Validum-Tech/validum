## Частые вопросы

**Это облачный сервис?**
Нет. Self-hosted: работает внутри периметра, наружу ничего не уходит.

**Можно генерировать боевые данные?**
Нет. Validum создаёт вымышленные данные, боевые персональные данные в тестовый контур попадать
не должны (152-ФЗ). Ответственность за то, что вы генерируете и куда кладёте, остаётся на операторе.

**Нужен справочник ЦБ?**
Для банковских сценариев — да: `fetch-bik -o data/ED807.xml`. Без него CLI отдаёт код `2`,
REST — `503 bik_source_missing`. Встроенного демо-справочника в продукте нет специально: один
источник правды вместо тихого отката.

**Почему прогон на следующий день даёт другой набор?**
`--seed` фиксирует значения, `--as-of` фиксирует дату расчёта (возраст, срок действия паспорта).
Без `--as-of` берётся сегодняшняя дата.

**Есть Maven Central?**
Да: `io.github.validum-tech:validum-core`, `validum-allure` и `validum-api` — см.
[QUICKSTART](QUICKSTART.md).

**JUnit 4 или pytest?**
JUnit 5/6 — через [Allure Extension](INTEGRATIONS.md); для остальных языков — REST или CLI.
